# Silicon Witchery Scoop bucket

Scoop manifests for Silicon Witchery software. The contents of this repository
are generated on release by GoReleaser. Do not edit them by hand.

## Superstack CLI

```sh
scoop bucket add siliconwitchery https://github.com/siliconwitchery/scoop-bucket
scoop install superstack
```

To upgrade:

```sh
scoop update superstack
```

Source and issues: [siliconwitchery/superstack-cli](https://github.com/siliconwitchery/superstack-cli)
